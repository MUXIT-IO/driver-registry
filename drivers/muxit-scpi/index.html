Scpi

v1.3.1 DLL instruments by muxit

Generic SCPI instrument driver — works with any SCPI-compliant device (oscilloscopes, multimeters, function generators, power supplies, spectrum analyzers) over TCP/IP (LXI, raw socket port 5025), Serial (RS-232/USB-to-serial), or USBTMC (direct USB-B). Provides raw query/write access, configurable timeouts, init command sequences, and auto-connect with *IDN? identity query.

Changelog

## 1.3.1 ### Bug Fixes - Coalescing pump now captures the latest pending value **inside** the transport lock, after `EnforceCommandIntervalAsync`. The previous version sampled it at dequeue time, so writes that arrived during the interval wait spawned a fresh pump iteration each — turning `commandIntervalMs: 1000` into a slow staircase instead of a single jump. ### Internal - Bump every patch release so `Version` makes it easy to tell whether a running driver matches the source tree.
