Scpi

v1.3.0 DLL instruments by muxit

Generic SCPI instrument driver — works with any SCPI-compliant device (oscilloscopes, multimeters, function generators, power supplies, spectrum analyzers) over TCP/IP (LXI, raw socket port 5025), Serial (RS-232/USB-to-serial), or USBTMC (direct USB-B). Provides raw query/write access, configurable timeouts, init command sequences, and auto-connect with *IDN? identity query.

# Changelog ## 1.2.0 ### Features - Declarative SCPI schema: connectors can describe properties and methods with `config.scpi: { properties, methods }` entries (`voltage: { cmd: "VOLT", type: "float", unit: "V" }`) and the driver synthesises get/set/dispatch. Hand-written overrides still win so vendor quirks stay expressible. - On-demand `Details` documentation layer surfaced to the AI prompt and editor hover. ## 1.1.2 ### Bug Fixes - Mirror TX/RX to stdout when `config.debug === true` so transport-level traffic is captured in server logs alongside the driver's structured `scpi` stream. ## 1.1.1 Internal bump for version-verification testing — no user-facing changes. ## 1.1.0 ### Bug Fixes - Stale-response framing fix after reconfigure / timeout: the driver now drains the transport on re-connect, honours a configurable `settleMs` before the first query, and supports an explicit `resync()` action for scripts that need to force a clean slate. ## 1.0.0 Initial release.
