AudioSynth

v1.4.1 DLL utilities by muxit

Software audio synthesizer. Plays tones, musical notes, and short melodies — useful for lab-side audible notifications, robot/CNC feedback tones, and experiment-complete bell sounds. Streams Opus-encoded audio to every connected dashboard by default; can also (or instead) play locally via NAudio on Windows hosts. Four waveforms, ADSR envelopes, additive harmonics, and presets (beep / bell / pluck / pad / marimba).

Changelog

## 1.4.1 ### Internal - Streaming path moved off Concentus and onto the new SDK `AudioStreamEmitter` API. The driver now hands the host a pre-rendered float buffer per note; the host owns Opus encoding, framing, real-time pacing, and stop-frame emission. The wire format is unchanged and Concentus no longer ships in the AudioSynth `.muxdriver` package — it lives once in MuxitServer alongside the central `AudioStreamEncoder`. ### Notes - No driver-author-visible behavior change. Existing connector configs and scripts continue to work without modification.
